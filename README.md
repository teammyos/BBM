# BBM
אתר BBM – עיריית בני ברק: ניהול נכסים ומשימות. מוצג תחת https://myos.co.il/BBM

## מבנה
| תיקייה / קובץ | תפקיד |
|---|---|
| `index.html`, `login.html` | דף הבית וכניסה |
| `assets/` | אזור הנכסים: רשימה (`index.html`), כרטיס (`asset.html`), עריכה (`edit.html`), תמורות, תמונת מצב |
| `js/config.js` | חיבור ל-Supabase. ריק = מצב הדגמה |
| `js/data.js` | שכבת הנתונים והלוגיקה העסקית |
| `js/lookups.js` | רשימות המערכת (מקור יחיד) |
| `js/demo-data.js` | נתוני דוגמה בדויים |
| `js/ui.js`, `css/app.css` | ממשק משותף |
| `supabase/` | סכמת מסד הנתונים. `002_lookups.sql` נוצר מ-`node tools/gen-lookups-sql.js` |
| `docs/supabase-setup.md` | מדריך הקמת Supabase |

## כללים
- המאגר ציבורי: אין בו נתוני נכסים, סיסמאות או מפתח `service_role`.
- קישורים יחסיים בלבד (האתר יושב תחת `/BBM/`).
- מסמכים (חוזים, הסכמים) נשארים בתיקייה המקומית של העירייה; במערכת נשמר רק הנתיב.
